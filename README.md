# Software Engineering Support Materials

This repository contains tutorials and reference material for software engineering, C# programming and the use of AI in software development.

## Guides

- [AI Programming with Visual Studio](VisualStudioAIprogramming.md)
	A practical project demonstrating AI-assisted programming in Visual Studio, with an emphasis on reviewing and improving generated code.

- [Artificial Intelligence and Software Engineering](ArtificialIntelligence_and_SoftwareEngineering.md) 
	
	Discusses how AI may affect software engineering and why human oversight remains important.

- [Console Project Tutorial](ConsoleProjectTutorial.md) 

	Introduces Visual Studio console projects, namespaces, libraries, input and a BMI programming exercise.

- [Exception Handling](ExceptionHandling.md) 

	Explains runtime exceptions and techniques for handling errors in C#.

- [Design Patterns](DesignPatterns.md) 

	Demonstrates the Factory design pattern using a shapes example, then further describes some other design patterns..

- [GDI Example](GDIexample.md)

	Shows how to draw and respond to events in a Windows Forms application using GDI.

- [Inheritance, Polymorphism, Abstract Classes, and Interfaces](InheritancePolymorphismAbstractClassesInterfaces.md) 

	Provides a worked example of core object-oriented programming concepts.

- [Introduction and Language Comparison](IntroductionLanguageComparison.md) 

	Compares C#, Java, and C++, including their platforms, features, and common uses.

- [Large Language Models](LargeLanguageModels.md)

	Introduces how LLMs work, local model options, coding applications, and limitations.

- [Local LLM Setup](LocalLLMsetup.md) 

	Guides you through running a local language model and connecting it to Visual Studio.

- [Publishing Documentation](PublishingDocumentationTutorial.md) 

	Covers generating API documentation with DocFX and publishing it with GitHub Pages and Actions.

- [Threads and Delegates](ThreadsAndDelegates.md) 

	Introduces concurrency, delegates, and thread examples in C# and Java.

- [Unit Testing Windows Projects](UnitTestingWindowsProjects.md) 

	Explains how to configure an MSTest project to reference a Windows Forms project.

- [Using GitHub with AI](UsingGitHubWIthAI.md) 

	Walks through using branches and pull requests to review AI-assisted changes.
